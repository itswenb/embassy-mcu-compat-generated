# embassy-mcu-compat-generated

由 embassy-mcu-compat 的 `./d gen-all` 生成；请在工具库修改输入、规则和模板，不手改本仓库产物。

`data/{chips,registers}` 保存 GD 原生结构化数据，`mcu-metapac/` 是统一兼容 PAC。不包含 ST 全型号、原始厂商源码、开发报告或缓存。必要的上游共享定义与许可说明保留。

当前仅开放 GD32F30x 理论集成；数据保留与驱动开放分开管理，其他系列仍待适配。PAC 采用 Embassy 兼容命名及经核验的行为适配，不等于原生数据的直接映射。

安装、型号对应 feature 和限制见 [使用说明](mcu-metapac/README.md)，来源与许可见 [UPSTREAM.md](UPSTREAM.md)。
